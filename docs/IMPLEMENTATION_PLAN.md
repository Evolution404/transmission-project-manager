## P2：需求导入与物资

责任范围：导入接口、需求与物资迁移、浏览器解析Web Worker、字段映射与需求列表/详情、共享输入输出类型。

交付：多个Excel文件/工作表导入、映射模板、类型和业务校验、分片暂存及发布、同源幂等、疑似重复人工处理、变化预览、来源追溯。支持 `.xlsx` 和 `.csv`；旧 `.xls` 先提示另存为 `.xlsx`，不伪称支持。浏览器解析库在该阶段从官方源选定并锁定版本，避免将完整文件交给免费Worker解析。

验收：合成多表不同列名、重复文件、合法相同需求、缺字段、未知型号、未核实电压、负数/过精度数量；中断后继续；更改同一请求键负载产生冲突；失败批次不进入正式报表；5万行数据不一次返回前端或Worker。

## P3：储备转换（先重点验收）

责任范围：项目/分配/估算/分类表、归并及确认接口、四步转换向导、储备列表与详情。

交付：年度/类别/电压/线路建议分组；人工拆并；标准物资汇总与来源明细双视图；部分分配与剩余需求；物资/施工/其他费用；缺价标记；估算版本；需求类别到储备大类映射与共同费用分摊。

验收：100单位拆为60和40；重复提交及两人并发分配不超过100；相同型号不同单位不合并；未知价格与明确零价区分；类别重复标签不增加金额；混合项目分类金额和已知费用合计相等；单据/明细可反查源表行。

## P4：框架、协议及资金

责任范围：框架/协议/预算/流水迁移与API、费用页面、口径切换、金额与日期共享逻辑。

交付：框架年度目标；协议版本与有效期；子项目预算草稿/确认及多协议分配；独立预算发生/实际费用流水；更正冲销；原子记账与幂等；90%、80%和预算超框架事件。

验收：无协议不能确认发生；跨框架拒绝；一协议多子项目、一子项目多协议的金额不重复；预算不自动产生发生额；90%/80%精确边界；预算合计=框架不超额，超1分预警；预警不擅自硬阻断；0分母显示未配置；并发更新不漏记；旧版本不重复计入。

## P5：出库、实施、结算与反馈

责任范围：出库/实施/结算及范围关联、状态投影、相应界面和附件元数据/私有存取。

交付：项目出库快照和分批范围、实施完成量与实际物资使用、历史记录补录和待关联、结算覆盖及最终标记、四状态和部分进度、结算待办。储备与子项目沿用同一ID。

验收：四种组合均可表达；分批完成60/100不等于整条已实施；剩余未安排需求仍影响总状态；先结算后实施可用；撤销结算后重新待办；历史实施不造出库且关联后不重复统计；附件跨项目拒绝；已有出库不能被修改储备静默覆盖。
